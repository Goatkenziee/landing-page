# Landing Page

This is a simple landing page built with Next.js 14, TypeScript, and Tailwind CSS.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-github-username>/landing-page.git
   cd landing-page
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and visit `http://localhost:3000`

## Deployment

This project is deployed on Vercel. You can view it at [Landing Page Live](https://landing-page.vercel.app)
